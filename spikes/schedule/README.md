# 학사일정 생성기 — 시험판 (버릴 코드)

교무자동화도구 박스의 1번 도구(연간 학사일정 자동생성기)가 어떤 모습일지 확인하려고 만든 **시험판**입니다.
실제 도구는 이 결과를 바탕으로 새로 설계합니다.

## 쓰는 법

1. 페이지를 엽니다: https://cleveranawim-source.github.io/office-box/spikes/schedule/
2. 작년 학사일정 **구글시트 링크**를 붙여넣거나 **xlsx 파일**을 올립니다.
   (구글시트는 공유 설정이 ‘링크가 있는 모든 사용자 — 뷰어’여야 합니다.)
3. 작년 일정 탭·만들 학년도·학기 시작 주를 확인하고 **자동 배치하기**.
4. 화면에서 고친 뒤 **엑셀로 내려받기**. (고친 내용은 새로고침하면 사라집니다.)

시트는 브라우저 안에서만 처리되고 어디에도 저장·전송되지 않습니다.

## 하는 일

- 작년 행사를 **"같은 학기·같은 몇째 주·같은 요일"** 로 새해 달력에 배치
- 작년 공휴일은 빼고, 새해 공휴일·대체공휴일(2027·2028학년도 내장)을 넣음
- 행사 이름 안의 기간 날짜 `(14~21)` 등은 새해에 맞게 자동 수정 (✎ 표시)
- 오른쪽 **⚠ 확인 필요**: 새해 공휴일과 겹친 행사, 재량휴업일 (누르면 해당 날짜로 이동)
- **비교할 탭**을 고르면(예: 직접 만든 새해 1안) 같은 날짜에 놓인 비율과 차이를 보여 줌

## 한계

- “월 · 주 · 월~토” 주 단위 달력 모양 시트만 읽음 (학교마다 다른 양식은 다음 단계)
- 재량휴업일·선택과목 회차(♧♡) 재계산은 아직 안 함
