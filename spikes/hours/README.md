# 시수계산기 — 시험판 (버릴 코드)

교무자동화도구 박스의 2번 도구가 어떤 모습일지 확인하려고 만든 **시험판**입니다.

## 쓰는 법

1. 페이지를 엽니다: https://cleveranawim-source.github.io/office-box/spikes/hours/
2. **학사일정**: 주 단위 학사일정 구글시트 링크나 xlsx를 넣습니다. [학사일정 생성기](../schedule/)에서 내려받은 엑셀도 됩니다.
3. **시간표**: `빈 양식 내려받기`로 받은 모양(첫 줄 `반 | 월1 … 금7`, 아래로 반마다 한 줄)에 과목을 채워 올립니다.
   먼저 둘러보려면 `예시 시간표 쓰기`(가짜 데이터)를 누릅니다.
4. **시수 계산하기** → 탭별로 확인 → **엑셀로 내려받기**.

시트는 브라우저 안에서만 처리되고 어디에도 저장·전송되지 않습니다.

## 화면

- **반별 요약**: 학년별 반 × 과목 표. 확보 시수 / 기준 시수(주당 × 기준 주수), 모자라면 빨간 칸.
- **반 상세**: 과목별 학기 중간고사 전·기말고사 전·기말 후 수업 횟수, 확보·손실·기준. 과목을 누르면 빠지는 날짜·교시·사유.
- **요일별 수업일수**: 학년·학기별 전체 일수, 휴일·휴업, 출석일수, 종일 행사·고사, 수업일수.
- **행사 해석**: 학사일정 표기를 어떻게 읽었는지. 해석 못 한 것(주황)은 직접 고르면 바로 다시 계산.

## 표기 해석 규칙

| 표기 | 해석 |
|---|---|
| `입학식1-4`, `안전교육2` | 끝의 숫자 = 교시 |
| `(2,3학년) …`, `1학년 …` | 해당 학년에만 적용 |
| 공휴일·대체공휴일·재량휴업일·`방학` | 그날 수업 없음 |
| `대학수학능력시험` | 휴업(시험장 학교) — 아니면 바꾸기 |
| `…고사`(교시 없음), 체육한마당·역사탐방·나들이, `수련회1`(숫자 = 며칠째) | 종일 |
| `★월요일 시간표 운영★` | 그날은 월요일 시간표로 계산 |
| 교직원·부장회의·학부모·상담주간·캠페인·마감 등, `(08:30~09:10)` | 학생 수업과 무관 |
| `6(1)` 같은 교시 바꿈, 교시 없는 기타 행사 | 해석 필요(주황) |

## 2026 시트로 확인한 것

- 출석일수(전체 − 휴일·휴업)는 시트에 손으로 계산된 값과 1·2학기 모두 일치.
- 수업일수는 학교 판단이 들어가 차이가 있음 → `종일 빠진 날만 / 절반 이상 빠진 날까지` 중 고를 수 있음.
